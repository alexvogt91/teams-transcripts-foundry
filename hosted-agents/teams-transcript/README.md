# Hosted transcript agent

Python 3.12, Responses 2.0 on port 8088 and pinned Agent Framework packages.
Exactly three native tools expose organizer-private listing, hybrid search and generation-pinned canonical pages.
The runtime resolves authenticated caller scope before opening the data plane and never accepts a caller ID from a model argument.
The hosted identity has only the dedicated transcript database's Cosmos Data Reader grant.

See the root [README](../../README.md) for portable staged deployment, delegated CLI acceptance, Foundry playground use, permissions and rollback.
`harness/deploy.py` creates an unpromoted candidate; `scripts/manage.py grant-agent` applies its database reader permission, and `harness/activate.py` requires delegated native reads before promotion.
The identity probe accepts zero neighboring containers and checks denial on every neighboring container discovered at deployment.
Secrets are not saved in local configuration/state or printed; limit Foundry version-management access because the embedding credential is supplied in the hosted version environment.
